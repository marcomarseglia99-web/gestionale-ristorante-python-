# Gestionale Ristorante Python

## Descrizione

Progetto didattico sviluppato in Python per simulare la gestione di un ristorante attraverso un'interfaccia a menu nel terminale.

Il programma utilizza la programmazione orientata agli oggetti (OOP) e organizza le funzionalità in moduli separati.

## Funzionalità principali

- Gestione del menu e dei piatti.
- Inserimento, modifica e rimozione dei piatti.
- Ricerca dei piatti e filtro per categoria.
- Gestione dei tavoli e del loro stato.
- Apertura e chiusura degli ordini.
- Aggiunta e rimozione dei piatti dagli ordini.
- Calcolo dei totali e degli scontrini.
- Report degli incassi e delle vendite.
- Gestione degli errori tramite eccezioni personalizzate.

## Tecnologie utilizzate

- Python 3
- Programmazione orientata agli oggetti (OOP)
- Classi, metodi e proprietà
- Liste e dizionari
- Gestione delle eccezioni
- Organizzazione modulare del codice
- Unittest per i test automatici
- Visual Studio Code
